# Patchen's — local demo

This is a fictional Nigerian catering and event styling concept. Its sample copy, menu, email, WhatsApp number, and imagery do not describe a real business or client.

## Preview

1. Keep `index.html`, `styles.css`, and `script.js` together in the same folder.
2. Open `index.html` in a current browser. The page works without a build step or JavaScript library.
3. The font and photo URLs load from the internet. For an offline version, replace them with local files (and use system fonts).

## Make it yours

- **Brand and wording:** edit the text in `index.html`; search for `Patchen’s` and `fictional` to find the demo labels.
- **WhatsApp:** in `index.html`, find `https://wa.me/2348000000000`. Replace the digits with the real country code and number, without `+`, spaces, or punctuation. Update the prefilled message after `?text=` if you want.
- **Email:** replace `hello@example.com` and the `mailto:` address in the enquiry section.
- **Photos:** replace the `images.unsplash.com` and Wikimedia Commons image URLs in `index.html` and the hero background URL near the final `.hero-image` rule in `styles.css`. Use images you own or have permission to use. If you move photos into this folder, use paths such as `images/your-photo.jpg`.
- **Colors:** adjust the custom properties at the top of `styles.css` (`--sand`, `--paper`, `--ink`, and `--olive`).

The 3D plate overlay has been removed from the hero. The orb remains a CSS-built decorative 3D-style element; there is no paid 3D service or external 3D library. The layout adapts to mobile screens and disables motion when a visitor requests reduced motion.
